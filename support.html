Getting Started

movie to gif makes it easy to convert videos into high-quality, lightweight GIFs with professional control over quality, frame rate, and resolution.

Quick Start Guide

  1. Import Video: Click to select a video file from your Mac
  2. Trim (Optional): Set start and end times to capture the exact segment you need
  3. Adjust Settings:
    • Quality: 50-100% (higher = more detail, larger file)
    • FPS: 1-30 frames per second (higher = smoother motion)
    • Max Width: 240-1080px (controls resolution)
  4. Preview: Check the real-time file size estimate
  5. Create GIF: Export and share your optimized GIF

Frequently Asked Questions

How do I reduce file size?
Lower the quality setting, reduce FPS, decrease max width, or trim to a shorter duration. The app shows real-time file size estimates to help you optimize.
What video formats are supported?
movie to gif supports all standard video formats including MP4, MOV, M4V, AVI, and more—any format your Mac can play.
What's the recommended quality setting?
80% quality provides an excellent balance of visual clarity and file size for most use cases. Adjust based on your needs—higher for detailed content, lower for simple animations.
Why does my GIF look compressed?
movie to gif uses JPEG-based compression to create smaller files. If you need more detail, increase the quality slider. Note that GIF format itself has inherent limitations compared to video.
What FPS should I use?
10-15 FPS works well for most content. Use higher FPS (20-30) for smooth motion or lower FPS (5-10) for smaller files and simple animations.
Can I convert long videos?
Yes, but longer videos create larger GIF files. Use the trim feature to select specific segments. For best results, keep GIFs under 10 seconds.
Is my video data private?
Yes. All processing happens locally on your Mac. Your videos never leave your device or get uploaded to any server.
Where are my GIFs saved?
After creating a GIF, use the share sheet to save to Files, share via Messages/Mail, or export to any destination you choose.

Tips & Best Practices

Optimize for Social Media

  • Twitter/X: Max 15MB, recommend 480px width, 10-15 FPS, 70-80% quality
  • Discord: Max 8MB (free) / 50MB (Nitro), recommend 480px width, 10-15 FPS
  • Slack: Max 1GB but keep under 5MB for fast loading
  • iMessage: No strict limit but keep under 10MB for reliable delivery

Quality vs. File Size

  • High quality (90-100%): Best for detailed graphics, text, or UI demonstrations
  • Medium quality (70-85%): Balanced option for most content
  • Low quality (50-65%): Simple animations, memes, or when file size is critical

Performance Tips

  • Shorter duration = faster processing and smaller files
  • Lower resolution reduces processing time significantly
  • Very high FPS (25-30) increases processing time and file size

Troubleshooting

GIF file is too large

  • Reduce quality setting
  • Lower FPS (try 8-10 instead of 15-20)
  • Decrease max width
  • Trim to a shorter duration

GIF looks blurry or pixelated

  • Increase quality setting
  • Increase max width (if source video is high resolution)
  • Ensure source video is good quality

Processing takes a long time

  • Reduce max width
  • Lower FPS
  • Trim to shorter duration
  • Close other resource-intensive apps

Can't import my video

  • Ensure the video file isn't corrupted
  • Try converting the video to MP4 or MOV format first
  • Check that you have read permissions for the file
